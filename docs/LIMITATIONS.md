# Limitations

- The score is a hand-coded, uncalibrated heuristic and has no clinical validity.
- No patient cohort, dataset provenance, accuracy, sensitivity, specificity, fairness, or outcome evidence is claimed.
- Inputs and outputs must be synthetic.
- Persistence is local and opt-in; the API has no user authentication or tenant isolation.
- Rules mode is verified. llama.cpp and OpenAI-compatible provider profiles are not release-verified.
- Windows Chromium is visually audited; physical Android/iOS accessibility is not verified.
- The repository still contains a historical root-level prototype outside the canonical packages.
- No public deployment, production user, medical efficacy, or support SLA is claimed.
- Full-history secret scanning reports two redacted historical Google API keys; provider-console restriction/rotation remains a human checkpoint.
